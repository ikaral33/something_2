init - инициализация работы git в определенном репозитории (взятие под взор репозитория гитом) git init
add - закидывает файлы в "индекс" гита. Индекс гита - файлы, готовые к коммиту git add {filename} git add . (все файлы)
commit - сохранение файлов в системе git. git commit -m "{something_to_say}"
log - вывод всех коммитов в данном репо. git log
push - загрузка коммитов в ветку репо на GitHub. git push origin master - origin(имя рабочего репо) master(ветка, в которую выгружается)
pull - получение и обновление новой версии репозитория + получение всех коммитов git pull origin master
clone - скачать репозиторий на свою машину git clone {url_git_repo}
branch - показывает все ветки репозитория
git branch {название} - создание новой ветки с новым названием
