Базовые команды:

<---НАВИГАЦИЯ--->

pwd - показывает текущий путь
ls - список файлов и папок (ls -la - подробный список со скрытыми файлами)
cd <путь> - перейти в директорию

<---Файлы и папки--->

mkdir <имя> - создать директорию (флаг -p(parent) - для создания вложенных папок (mkdir -p a/b - создание дир. b в созданной дир. a) )
touch <имя> - создание пустого файла
cp <источник> <назначение> - копирования одного файла в другой (флаг -r - для папок)
mv <источник> <назначение> - перемещение или переименование файла/папки
rm <файл> - удаление файла (-rf <папка> - удаление папку без подтверждения)

<---Просмотр и поиск текста--->

cat <файл> - открытие файла
less <файл> - открытие в постраничном виде
grep "текст" <файл> - поиск строки с заданным текстом (grep -r "текст" <папка> - поиск строки в директории)
find <путь> -name "*.log" - поиск файла по имени или маске (*.log - любые символы в названии с расширением .log)

<---Права доступа и пользователи--->
sudo <команда> - выполнить команду от лица root
chmod <параметры> <файл> - установка параметров доступа для файла

	<параметры> записываются либо численно, либо буквенно
	численные параметры 1 - x (исполнение), 2 - w (изменение), 4 - r (чтение), их сумма и указывает на права
	положение в строке указывает на категорию пользователей, l__ - владелец, _l_ - группа, __l - остальные
	777 - все для всех, 774 - все для владельца и группы, чтение - для остальных

	<параметры> могут также записываться буквами
	u - владелец, g - группа, o - остальные, + разрешение, -  запрет, = присвоение, r - чтение, w - запись, x - выполнение
	u+rwx, g-rx, a=w - добавление всех прав для владельца, убрать чтение и выполнение для группы, для остальных назначить только чтение

chown <пользователь>:<группа> <путь> - изменение пользователя и группы выбранного файла (chown <пользователь> <путь> - только пользователь, 
флаг --from позволяет задать условие изменение по названию владельца (--from=root:root www-data:ww-data - передача файлов от root:root к www-data:www-data)

<---Мониторинг--->
ps aux - статический снимок процессов на момент запуска программы (флаги a - процессы всех юзеров, u - подробный формат, x - фоновые процессы без привязки к терминалу)
top - базовый интерактивный мониторинг






load average (la) - количество процессов, которые, в среднем, работают в течении 1, 5 и 15 минут, цифры означают, сколько ядер полностью загружено (1.0 - полностью загружено)
la не считает загрузку процессора, оно отражает общую нагрузку системы, т.е. считается процессы в двух состояниях: R (runnable/running), которые выполняются прямо сейчас, и D (uninterruptible sleep), которые ждут какого-то ресурса и они не могут быть прерваны. Следовательно, la показывает общую очередь процессов, cpu + disk, а cpu utilization показывает, сколько процессор загружен вычислениями
